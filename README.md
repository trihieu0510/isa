# ISA CUHK — Website

Official website for the International Students Association (ISA) of The Chinese University of Hong Kong.
Static site (plain HTML / CSS / JS) — no build step, hosts anywhere.

## Structure
```
ISA_website/
├── index.html          # Home — hero, about, what-we-do, events preview, team preview, gallery preview, join CTA
├── events.html         # Events — click any event for its photos + an overview
├── gallery.html        # Full gallery — filterable (Events / Cabinet / Campus Life) + lightbox
├── team.html           # The 17th Cabinet by department + Past Cabinets (15th & 16th)
├── join.html           # Membership registration form + payment section
├── css/
│   └── styles.css      # CUHK purple + gold theme, responsive, all interactivity
├── js/
│   ├── main.js                # Page-aware: nav, gallery, events, team, past cabinets, lightbox, form, animations
│   ├── gallery-data.js        # Gallery photos (generated)
│   ├── gallery-extra.js       # Real event photos added to the gallery (generated)
│   ├── events-data.js         # Events + overviews (generated)
│   ├── team-data.js           # 17th cabinet roster (generated)
│   └── past-cabinets-data.js  # 15th & 16th cabinets (generated)
├── assets/
│   ├── images/         # Logo, hero, about/what-we-do photos
│   ├── gallery/        # Sorted gallery photos — events/ cabinet/ campus-life/
│   ├── events/         # Per-event photo sets (one folder per event)
│   ├── team/           # 17th cabinet photos
│   └── past-cabinets/  # 15th & 16th cabinet cards
├── build/              # PowerShell tools that regenerate the data — see build/BUILD.md
└── README.md
```

> The `js/*-data.js` files and everything under `assets/` are generated by the scripts in
> `build/`. The site runs entirely on what's committed here — no build step or source
> material is needed to deploy. See `build/BUILD.md` to refresh content later.

## Run it locally
Open `index.html` in a browser, or serve it:
```bash
python -m http.server 8000   # then visit http://localhost:8000
```

## Before going live
1. **Registration form (Formspree):** sign up at https://formspree.io, create a form, and
   in `join.html` replace `YOUR_FORM_ID` in `action="https://formspree.io/f/YOUR_FORM_ID"`.
2. **Payment:** the Join page has a "coming soon" payment card — wire in a provider
   (Stripe link / PayPal / FPS-PayMe QR) when ready.
3. **Brand colors:** `--purple` and `--gold` in `css/styles.css` are close approximations of
   CUHK's purple & gold — swap in the official hex codes if you have them.
4. Contact details (Instagram `@isa.cuhk`, email `isa.cuhk@gmail.com`) are already set.

## Hosting (free options)
- **Netlify** — drag-and-drop the folder. (Netlify Forms can also replace Formspree.)
- **GitHub Pages** — push to a repo, enable Pages.
- **Cloudflare Pages** — connect a repo or upload.
